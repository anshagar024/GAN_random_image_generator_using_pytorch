# Generative Adversarial Network (GAN) using PyTorch

## Overview
This project implements a Generative Adversarial Network (GAN) using PyTorch to explore deep learning and generative AI.

## Technologies Used
- Python
- PyTorch
- NumPy
- Matplotlib

## Model Architecture
The GAN consists of two neural networks:

- **Generator:** Generates synthetic samples.
- **Discriminator:** Distinguishes between real and generated samples.

## Key Concepts
- Deep Learning
- Generative AI
- Adversarial Training
- Neural Networks
